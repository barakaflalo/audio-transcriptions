שימוש באפליקציה

מפתחות וספקים חיצוניים (BYOK)

המשתמש מחבר מפתח API אישי ובוחר ספק. השימוש, המכסות, העלויות ושמירת המידע אצל הספק כפופים לתנאי הספק. AppNest אינה מתווכת את הבקשות ואינה מקבלת את המפתח או את תוכן התמלול.

תוכן והרשאות

יש להעלות, להקליט או להוריד רק תוכן שיש למשתמש זכות חוקית לעבד. המשתמש אחראי לקבלת הסכמות להקלטת אנשים ולשמירה על זכויות יוצרים, פרטיות וסודיות.

שמירה וגיבוי

המידע נשמר בעיקר במכשיר ובדפדפן. מחיקת נתוני הדפדפן, החלפת מכשיר או תקלה עלולות להסיר מידע. מומלץ ליצור גיבויים תקופתיים ולשמור אותם במקום מוגן. גיבוי מלא עם מפתחות API מכיל סודות בטקסט גלוי.

זמינות ואחריות

תכונות מסוימות תלויות בדפדפן, במערכת ההפעלה, בחיבור האינטרנט ובספקי צד שלישי. השירות ניתן כפי שהוא, ללא התחייבות לזמינות רציפה או לדיוק מלא.
